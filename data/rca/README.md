# Root Cause Analysis (RCA) Ground-Truth Data

## Purpose
This directory stores ground-truth Root Cause Analysis diagnoses, failure mechanisms, evidence logs, and advisory recommendations extracted from datasets.

## Ground-Truth Attributes
- `problem`
- `probable_root_cause`
- `evidence` (list of factual indicators)
- `impact`
- `recommendation` (advisory instructions)
- `confidence` (0.0 to 1.0 calibration)
